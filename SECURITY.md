# Security Policy

## Supported Versions

Currently, only the latest version (0.6.3) is supported.

| Version | Supported          |
| ------- | ------------------ |
| 0.6.3   | :white_check_mark: |
| < 0.6.3  | :x:                |


## Reporting a Vulnerability

Please report any P1 vulnerabilities, directly to the project author.  Any and all others can and should generated a new "Issue" within this project.
