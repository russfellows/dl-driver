# Release Notes: dl-driver v0.8.1

**Release Date:** October 22, 2025  
**Branch:** v0.8.0-phase3-controller  
**Focus:** Histogram-Based Percentile Aggregation & Results Directory Support

## Overview

Version 0.8.1 delivers **statistically correct performance metrics** for distributed workloads through HDR histogram aggregation. This release solves the critical problem of inaccurate percentile reporting when aggregating results from multiple agents with unbalanced workloads.

## 🎯 Key Features

### 1. HDR Histogram Aggregation

**Problem Solved:** Naive averaging of percentiles (p50, p90, p95, p99) from multiple agents produces errors exceeding 50% for unbalanced workloads.

**Solution:** HDR Histogram-based aggregation that:
- Tracks full latency distributions (not just percentiles)
- Merges histograms from all agents before calculating percentiles
- Produces statistically correct aggregate percentiles
- Uses V2 deflate compression for efficient transport (10-50x reduction)

**Implementation:**
- `crates/core/src/dist/histogram.rs` - Serialization, deserialization, merging
- `crates/core/src/metrics.rs` - Size-bucketed histogram collection
- `crates/core/src/dist/types.rs` - `from_results_with_histograms()` method

**Validation:** See `crates/cli/tests/histogram_integration_test.rs` for proof of accuracy improvements.

### 2. Comprehensive Results Directory

**Inspired by:** sai3-bench results format  
**Directory Structure:**
```
dlio-YYYYMMDD-HHMM-{test_name}/
├── config.yaml              # Input config (reproducibility)
├── console.log              # Execution timeline
├── metadata.json            # Run metadata
├── storage_results.tsv      # Consolidated storage metrics
├── aiml_results.tsv        # Consolidated AI/ML metrics
└── agents/                  # Per-agent results
    ├── agent-0/
    │   ├── storage_results.tsv
    │   ├── aiml_results.tsv
    │   └── metadata.json
    └── ...
```

**Features:**
- Timestamped directories for easy comparison
- Self-contained (config + results + metadata)
- Machine-readable TSV format
- Per-agent and aggregate views

**Implementation:**
- `crates/core/src/results_dir.rs` - Directory management
- `crates/core/src/tsv_export.rs` - TSV formatting
- `crates/core/src/dist/controller.rs` - `run_distributed_with_results()`

### 3. Size-Bucketed Byte Tracking

**Problem Solved:** TSV exports were estimating throughput from bucket midpoints instead of tracking actual bytes transferred.

**Solution:** `SizeBins` structure tracks actual operations and bytes per size bucket:

```rust
pub struct SizeBins {
    // bucket_index -> (ops, bytes)
    pub by_bucket: HashMap<usize, (u64, u64)>,
}
```

**Benefits:**
- Accurate throughput calculations
- Per-size-range performance analysis
- Real data vs estimates

**Implementation:**
- 9 size buckets: zero, 1B-8KiB, 8KiB-64KiB, ..., >2GiB
- Integrated into `StorageOpHists` for automatic tracking
- Used in TSV export for precise metrics

## 🔧 Technical Details

### Histogram Parameters

- **Range:** 1μs to 1 hour (3.6e9 μs)
- **Precision:** 3 significant figures
- **Compression:** V2 deflate (HdrHistogram standard)
- **Transport:** Binary protobuf bytes field

### Size Buckets

| Bucket | Range | Typical Use Case |
|--------|-------|------------------|
| 0 | Zero bytes | Empty files |
| 1 | 1B - 8KiB | Metadata, small configs |
| 2 | 8KiB - 64KiB | JSON configs, small images |
| 3 | 64KiB - 512KiB | Medium data chunks |
| 4 | 512KiB - 4MiB | Image tiles, audio |
| 5 | 4MiB - 32MiB | Large images, video chunks |
| 6 | 32MiB - 256MiB | Model checkpoints |
| 7 | 256MiB - 2GiB | Large datasets |
| 8 | > 2GiB | Huge files |

### Performance Overhead

- **Histogram recording:** <1% CPU overhead
- **Memory per histogram:** ~10KB
- **Serialization:** ~50μs per histogram
- **Network transfer:** ~2KB compressed per histogram
- **Merge time:** <10ms for 100 agents

### New Public Methods

```rust
// Controller
impl Controller {
    pub async fn run_distributed_with_results(
        &self,
        config_path: Option<&Path>,
        output_dir: Option<&Path>,
    ) -> Result<AggregateResults>;

// AggregateResults
impl AggregateResults {
    pub fn from_results_with_histograms(
        results: Vec<WorkloadResult>,
        summaries: &[WorkloadSummary],

    pub fn to_storage_tsv(&self) -> String;
    pub fn to_aiml_tsv(&self) -> String;

// ResultsDir
impl ResultsDir {

    pub fn create_agents_dir(&mut self) -> Result<PathBuf>;
    pub fn finalize(&mut self, duration_secs: f64, successful_agents: usize) -> Result<()>;
}
```

    Some(Path::new("/results")),
