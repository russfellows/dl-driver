# dl-driver v0.7.0 Release Notes

**Release Date:** October 3, 2025  
**Branch:** release/v0.7.0  
**Previous Version:** v0.6.7

## 🎯 Release Overview

Version 0.7.0 represents a major infrastructure upgrade, bringing dl-driver up to date with the latest s3dlio capabilities and implementing a sophisticated multi-level logging system. This release focuses on dependency modernization, improved observability, and laying the groundwork for advanced operation replay functionality.

## 🚀 Major Features

### 1. s3dlio v0.8.19 Integration
- **Upgraded from v0.8.7 to v0.8.19** with 12 minor versions of improvements
- **Added s3dlio-oplog dependency** for shared operation log functionality
- **Removed AWS patch** - no longer needed with s3dlio v0.8.19
- **Resolved version conflicts** - eliminated dual s3dlio versions in dependency tree
- **Clean dependency tree** - single unified s3dlio version throughout

### 2. Multi-Level Logging System
```bash
# Default: Warnings only (clean output)
dl-driver run --config config.yaml

# Level 1: INFO for both dl-driver and s3dlio (progress from both)
dl-driver -v run --config config.yaml

# Level 2: DEBUG for dl-driver, INFO for s3dlio (internals + progress)
dl-driver -vv run --config config.yaml

# Level 3: TRACE for dl-driver, DEBUG for s3dlio (maximum detail)
dl-driver -vvv run --config config.yaml
```

Key improvements:
- **Better s3dlio visibility**: `-v` now shows s3dlio INFO messages (was suppressed)
- **Granular control**: Different verbosity levels for dl-driver vs s3dlio
- **Robust initialization**: Fixed panic when global subscriber already set
- **Test compatibility**: Improved from 71/77 to 76/77 passing tests

### 3. Workspace Version Management
- **Centralized versioning**: Added `[workspace.package]` with version = "0.7.0"
- **Version inheritance**: All crates use `version.workspace = true`
- **Simplified updates**: Single source of truth for version numbers
- **Modern Rust practices**: Leverages Rust 1.90+ workspace inheritance
